# Motion Template Library

Reusable asset library for the automatic documentary pipeline's motion-graphics module. Generated by the scaffold cell - re-run it to regenerate from scratch, or hand-edit individual files (regeneration overwrites, so copy anything you've customized before re-running).

## Folder structure

```
motion_templates/
  engine/
    motion_engine.py      # elem(), render_element(), morph(), slide_handoff_html(),
                          # cut_html(), Sequence - shared by every state & template
  states/                 # 30 files - the atomic, reusable pieces
    st_01_title_a.py ...
  templates/               # 20 files - states chained together via morph
    tpl_01_title_intro.py ...
  registry/
    registry.json          # machine-readable catalog of everything below
  docs/
    TEMPLATES.md            # this file
```

## Core concepts (recap)

- A **state** is a pure function `state(p: float) -> dict` returning named elements (`elem(kind, x, y, w, h, opacity, scale, rotation, **content)`).
- A **template** chains 2-3 states from the *same category* with `morph()` - states within one template are always similar by construction, so the internal transition is always morph.
- Between two *different* templates in your final documentary sequence: if they share a category/family, keep using `morph`; if not, use `slide_handoff_html` (whole composition exits bottom-left / enters top-right) or `cut_html` (instant swap). This decision is made by you when you write the sequence - it is not auto-detected.
- `morph()` matches elements by **name**: same name + same content -> pure geometry interpolation (an element visibly moving/resizing). Same name + different content -> cross-dissolve while moving. Name only on one side -> fade in/out.

## Using a template

```python
import sys

sys.path.append('/content/drive/MyDrive/uber_project/assets/motion_templates/templates')
sys.path.append('/content/drive/MyDrive/uber_project/assets/motion_templates/states')
sys.path.append('/content/drive/MyDrive/uber_project/assets/motion_templates/engine')
import tpl_02_stat_full as tpl

seq = tpl.build_sequence()
html = seq.html_at(3.5)  # frame HTML at t=3.5s
```

## Chaining two templates in a documentary sequence

```python
from motion_engine import morph, slide_handoff_html, render_elements

# same category -> morph
frame = render_elements(morph(state_a_end, state_b_start, mix))

# different category -> slide handoff
frame = slide_handoff_html(state_a_end, state_b_start, mix)
```

## Adding a new state or template

1. Pick (or add) a category in `CATEGORIES` inside the scaffold cell.
2. If it fits an existing family (banner/stat/compare/quote/timeline/list/map/feature/chart/closing), just add the category entry with its text fields - the family emitter builds it automatically.
3. If it needs a genuinely new layout, write a new `family_<name>(cat)` function returning `(a, b, c)` element dicts, register it in `FAMILY_EMITTERS`, and list its `exposes` in `FAMILY_EXPOSES`.
4. Re-run the scaffold cell. It regenerates every file and `registry.json` from scratch - hand-edits to generated files will be overwritten.
